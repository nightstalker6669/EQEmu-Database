# Achievement SQL source coverage

This batch collects the existing SQL sources from sixteen versioned achievement content packages. It is neither a complete server installer nor a statement that every source file is installed/enabled. Per-package manifests pin actual SQL bytes, original owner-manifest hashes, configuration/provenance references and sequencing-tool identities. SOURCE-README preserves original prerequisites, defaults, unresolved rewards and native limitations.

Use the original guarded installer/source sequencing for each package; do not blindly sort or replay this collection. Foundation source dependencies run Crescent; Blightfire foundation/families and StoneHive; required Blightfire parent rewards; Mesa and full remaining extension; Roost; Steppes, followed by its later dependent packages. ShardsLanding has separate foundation/prerequisite requirements. The source guides are authoritative for exact local order, required source/quest hooks, review/configuration values and activation phases. Disabled/review-required filenames retain original meaning; current file flags alone do not establish installed state.

The SQL set includes original configuration templates and state-schema prerequisites where owned by packages. Templates requiring selected defaults remain templates; a copied source template is not the actual configured installed payload. Historical/researched values, explicitly chosen defaults and unresolved details are preserved separately. Runtime content_db definitions differ from character/runtime custody; no current player rows, object_contents, journal contents or snapshots are exported.

Matched engine/schema and installed Lua/code dependencies remain separate from SQL application. Do not reapply archived C++patches to integrated source. Registry9329–9338 schema migrations are packaged separately from this content set. Xorbb9344/9345 and newer disabled proposals are not promoted into this retained content set;9345 remains unapplied despite source review/syntax acceptance.

No SQL/installer was run, no fixtures/imports or native tests were created. Retained owner application receipts are being reconciled into a separate coverage ledger. Original baseline clone/archive redistribution limits do not prevent publishing our own existing SQL changes. Source guide relative links target the original pinned repository layout; this SQL subset is not a replacement for the complete feature source/quests.
