# Prophecy of Ro group progression database

This database extends the published Darkhollow progression seed with the PoR group routes through Theater of Blood. Use the matched server and canonical quest files listed in SOURCE-MANIFEST.json.

## Fresh installation

Import full.sql into an empty MariaDB 10.11 database with a DELIMITER-aware client. The seed replaces tables. The five recorded SQL stages document how the seed was assembled. Keep existing player volumes separate from the fresh-install seed. This release has no existing-volume upgrade.

## Native verification

Native testing completed the core progression with scoped positioning and combat assistance. Earned chime and AA casts each reached public Theater of Blood. The database sets the public zone minimum to level 68. The independent level 67 and 68 probe cases and automatic AA delivery remain unverified.

- Native completion used scoped development positioning and combat assistance. The group included an elevated-status tester and invulnerability was enabled on two profiles.
- The physical Root of Ro ascent from C1 onward and the switch 1 exit were unverified. The Root test used a local asset replacement with no recoverable preimage hash.
- The unassisted approach to Kelshar, a landed Curse of Salir, and the patched Library v10 exit were unverified.
- Independent level 67 denial and level 68 admission using ordinary probe characters were unverified. Automatic level-based Harmonic Dissonance delivery was unverified.
- Sverag starts under Bolvirk control. Historical automatic controller takeover and rotation remain unverified.
