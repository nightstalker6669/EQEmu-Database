# PEQ RoF2 Tunare’s Shrine database

This matched seed adds the earned Tunare’s Shrine chain and restores the original public approach from Ro to Elddar Forest. Use the matching server and canonical quests pinned in SOURCE-CONTENT-BINDING.json. NATIVE-QUALIFICATIONS.json describes the accepted routes and test limits.

Import full.sql into a fresh empty database with MariaDB 10.11. It includes the published r33 seed followed by the four Tunare catalog files in order. Existing volumes and in-place upgrades are outside this package. Use a matching runtime configuration with Prophecy of Ro content enabled.

The database includes static content and empty custody definitions. QA identities, temporary flags and gear, live expeditions, player inventory and snapshots are excluded.
